# 調査メモ: 物理シミュレーション系ショート（2026-11）

## 伸びている型
- 「ボールは円から脱出できるか？」: 2023年11月にショートで初めてバズり、2026年も続いている定番
- 跳ねるたびにボールが大きくなる、または1個増える（「Every Bounce = +1 Ball」）
- プリンコ（落下したボールが釣鐘型の分布になるか）
- マーブルレース: ヒットは少数の当たり動画とチーム制シリーズから出る

## 伸びる要素
- 跳ねるたびに有名曲の音が1音ずつ鳴る（同期）
- だんだん激しくなる展開（速く、大きく、数が増える）と、結末への緊張感
- 色の変化、軌跡のエフェクト、効果音

## リスク
- 作成ツールが売られているほどの飽和ジャンル。テンプレのままだと YouTube の「inauthentic content（量産コンテンツ）」ポリシーでチャンネルごと収益化が止まる恐れ
- ショートの RPM は 1,000再生あたり 約$0.03〜0.15 と低い

## 方針
1. キャラクター化とシリーズ化（名前・チーム・リーグ戦・戦績）で、他との違いと継続視聴を作る
2. 音はパブリックドメインの曲を自前で合成（著作権リスクなし）
3. タイトルは英語で世界向け
4. ショートを週1で長尺の総集編にまとめる（RPM が高く、総再生時間も稼げる）
